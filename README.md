# reading-capture

本を読みながら、ページの写真と話した言葉を手間なく取り込むための Android アプリ（個人用）。

最終更新: 2026-11-20

## 状態

リポジトリを作った段階。コードはまだ無い。

## 作るもの

- カメラを本のページに向けると、ページが止まったところで自動で撮る。シャッターは押さない。1 ページずつ
- 撮れたら振動で知らせる。欄外が切れている、ぶれているときは別の振動で知らせる
- 入力欄に音声入力で話した言葉を、そのまま保存する（音声認識はアプリに持たせず、端末の音声入力を使う）
- 写真と話した言葉を、本人だけが見られる置き場に上げる

## 作り方

- Kotlin の Android アプリ。カメラの映像を自前で扱い、「動いた → 止まった」で撮る
- 本文の文字起こし（OCR）はしない。写真は切り抜かずに全体を保存する
- Mac でビルドして USB で端末に入れる。ストアには出さない

## このリポジトリに入れないもの

- 本のページの写真、本文
- アクセストークン、署名鍵、端末固有の設定（`.gitignore` で除外）
